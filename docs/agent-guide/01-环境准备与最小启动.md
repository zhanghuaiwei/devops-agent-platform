# 01 环境准备与最小启动

> 对应里程碑:W3。预计耗时:1 小时。

## 学习目标

- 建好 Python 3.12 虚拟环境,跑通 FastAPI 最小启动
- 理解依赖锁定策略(requirements vs pyproject)

## 步骤

### 1. Python 3.12

```bash
# macOS
brew install python@3.12
python3.12 --version   # 必须是 3.12.x
```

### 2. 虚拟环境(隔离红线:永远不污染系统 Python)

```bash
cd agent-engine
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements-dev.txt
```

### 3. 配置环境变量

```bash
cp .env.example .env
# 编辑 .env:LLM_API_KEY 填你的千问/DeepSeek Key(学习期推荐 qwen-turbo,便宜)
```

### 4. 启动验证

```bash
uvicorn app.main:app --reload --port 8000
curl http://localhost:8000/health        # {"status":"UP"}
open http://localhost:8000/docs          # FastAPI 自带 Swagger UI ——  schemas 即契约
```

`/docs` 页面是你定义的 Pydantic 模型自动生成的 —— **模型即契约**的直观体现。

### 5. 跑通质量门

```bash
pytest            # 冒烟测试应通过
ruff check .      # 0 错误
ruff format .     # 统一格式(与 pre-commit 共用同一配置)
```

## 验收清单

- [ ] `/health` 返回 UP
- [ ] `/docs` 能看到 4 个 agent 端点(虽然实现还是 TODO)
- [ ] pytest / ruff 全绿

## 知识卡片:为什么用 venv 而不是全局 pip install

两个项目依赖同一包的不同版本时全局安装必炸;venv 让每个项目有独立 site-packages。`.venv/` 已被 .gitignore 拦截。
