# 01 环境准备与项目初始化

> 对应里程碑:W1。预计耗时:1~2 小时。

## 学习目标

- 装好 Java 21 与 Maven,理解版本红线的意义
- 跑通 `server/` 多模块骨架的首次编译

## 步骤

### 1. 安装 Java 21

```bash
# macOS(Homebrew)
brew install openjdk@21
# 验证:必须显示 21.x
java -version
```

面试点:为什么是 21 而不是 17?——虚拟线程(Virtual Threads)在 21 正式转正,它是本项目 WebSocket 高并发(F1.2)的关键;`application.yml` 中 `spring.threads.virtual.enabled: true` 一行启用。

### 2. 安装 Maven 并生成 Wrapper

```bash
brew install maven
cd server
# 生成 mvnw + .mvn/wrapper(团队统一 Maven 版本,CI 里 ./mvnw 才能工作)
mvn -N wrapper:wrapper
```

### 3. 首次编译

```bash
cd server
./mvnw compile
```

预期:BUILD SUCCESS。若失败,最常见原因是网络拉不动依赖 —— 配置 `~/.m2/settings.xml` 阿里云镜像。

### 4. 启动基础设施(本教程只需要数据库和缓存)

```bash
cd devops
docker compose up -d postgres redis
docker compose ps   # 确认 5432/6379 端口就绪
```

### 5. IDE 配置(IntelliJ IDEA)

1. 打开 `server/` 目录(不是整个 monorepo 根)
2. 安装 EditorConfig 插件(自动应用 `.editorconfig`:4 空格缩进)
3. 启用 Annotation Processing(spring-boot-configuration-processor 生成配置元数据需要)

## 验收清单

- [ ] `java -version` 显示 21
- [ ] `./mvnw compile` 成功
- [ ] `docker compose ps` 中 postgres/redis 为 running

## 常见问题

| 问题 | 原因 | 解决 |
|------|------|------|
| `mvnw: Permission denied` | 无执行权限 | `chmod +x mvnw` |
| 依赖下载超时 | 默认中央仓库慢 | 配置阿里云镜像 |
| 编译报 "release version 21 not supported" | JAVA_HOME 指向旧 JDK | `export JAVA_HOME=$(/usr/libexec/java_home -v 21)` |
