# 工作流规约

1. **学习者优先**:`server/` 与 `agent-engine/` 中带 `TODO(学习者)` 标记的骨架文件是留给人类学习者手写的,AI 只讲解、不代写,除非用户明确说"帮我实现";面向学习者的输出以教程、评审、答疑为主
2. **先问后写**:需求模糊时,先列 2~4 个方案让用户选,不要猜;完善骨架或新增功能前,先确认所属功能点(F1.x)、是否触及学习者 TODO 区域
3. **小步提交**:一次只做一件事;单文件改动超过 ~300 行先拆任务
4. **交付即注释**:AI 生成的每个文件头部注明 `AI 生成`;关键决策处写清"为什么这么做"而非复述代码
5. **中文回复**,代码注释用中文
6. **禁止越界**:不得修改对方端口的内部实现;跨端问题走接口契约(`docs/architecture.md` 的 API 契约表)
7. **记忆**:里程碑式决策(如选型变更)写入项目记忆,便于跨会话延续
8. **列方案 + 举一反三**:回答方案/决策类问题时,按 `.ai/skills/option-presenter/SKILL.md` 执行——先列 2~4 个候选方案(思路/优点/代价/适用场景)并给推荐,结论之后做举一反三延伸;事实问答与明确指令除外
